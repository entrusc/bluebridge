# Bluebridge PCB

The Bluebridge board as an [EasyEDA Pro](https://pro.easyeda.com) project, in
one self-contained file: `bluebridge.epro2` bundles the schematic, the 2-layer
PCB, and all symbols/footprints it needs. No libraries or accounts required.

## Opening the file

1. Install EasyEDA Pro (free, Windows/macOS/Linux) from
   [pro.easyeda.com](https://pro.easyeda.com/en/download/index).
2. Choose **File → Open** (or **File → Import**, depending on version) and
   select `bluebridge.epro2`.
3. The project appears in the project navigator with its schematic and PCB
   sheets.

The file was saved with editor version 3.2.x. If your EasyEDA Pro is older,
update it before opening — older versions may not read the project.
